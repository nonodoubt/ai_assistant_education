# Сборка базы данных и валидация данных

## Общая схема

```
programs.xlsx  ─┐
                ├──▶  validate_programs.py  ──▶  build_db.py  ──▶  knowledge.db
FAQ.docx       ─┘         (проверка)             (сборка)          (база данных)
synonyms.json ──────────────────────────────────────┘
```

При запуске `build_db.py` автоматически проверяет `programs.xlsx` через `validate_programs.py`.
Если найдены критические ошибки — сборка отменяется, старая БД не удаляется, бот продолжает
работать на предыдущей версии.

---

## Файлы

| Файл | Расположение | Назначение |
|------|-------------|------------|
| `programs.xlsx` | `data/` | Каталог программ. Редактируется клиентом. |
| `FAQ.docx` | `data/` | Вопросы и ответы. Редактируется клиентом. |
| `synonyms.json` | `services/db/` | Словарь синонимов и тегов. Редактируется разработчиком. |
| `build_db.py` | `services/db/` | Скрипт сборки БД. |
| `validate_programs.py` | `services/db/` | Валидатор `programs.xlsx`. |
| `build_vectors.py` | `services/db/` | Генерация эмбеддингов (запускается после `build_db.py`). |
| `knowledge.db` | `services/db/` | Итоговая БД (создаётся автоматически). |

---

## Как запускать

### Полная пересборка БД

```bash
cd /home/ddt/bot
source .venv/bin/activate

# Шаг 1: сборка БД (включает валидацию автоматически)
python services/db/build_db.py

# Шаг 2: пересборка векторных эмбеддингов
python services/db/build_vectors.py

# Шаг 3: перезапуск бота, чтобы подхватил новую БД
sudo systemctl restart ddt-bot
```

### Только проверка файла (без сборки)

```bash
python services/db/validate_programs.py
```

Или для проверки произвольного файла:

```bash
python services/db/validate_programs.py /path/to/новый_programs.xlsx
```

## Структура programs.xlsx

### Обязательные колонки

| Колонка | Описание | Пример |
|---------|----------|--------|
| Направление | Категория программы | `Хореография` |
| Название коллектива | Полное название | `Хореографический ансамбль «Забава»` |
| Возраст | Возрастной диапазон | `7-12 лет` |
| Платное/Бюджет | Тип оплаты | `Бюджет` или `500 рублей / занятие` |
| Расписание | Дни и время занятий | `ПН, СР 16:00-17:30` |
| Площадка | Адрес | `пр. Раевского 5/2` |
| Что нужно для занятий | Требования | `Спортивная форма, сменная обувь` |
| Чему ребенок научится/ что изучит? | Результаты обучения | `Ритмика, координация, пластика` |
| Педагог | ФИО педагога | `Иванова А.С.` |
| Информация о педагоге | Квалификация, стаж | `Стаж 15 лет, 1 категория` |
| Ссылка на запись (навигатор) | URL для записи | `https://...` |
| теги | Ключевые слова через запятую | `танцы, активность, осанка, ритм` |

### Допустимые значения

**Платное/Бюджет** — строго одно из двух:
- `Бюджет`
- `500 рублей / занятие`

**Площадка** — строго одно из двух:
- `пр. Раевского 5/2`
- `пр Тореза 35/1`

**Возраст** — формат `N-M лет` или `N лет`:
- `3-4 года` ✅
- `7-12 лет` ✅
- `5 лет` ✅
- `7 лет (первоклассники)` ⚠️ (бот не распарсит пояснение в скобках)

**Теги** — через запятую, строчными буквами:
- `танцы, активность, осанка, ритм` ✅
- `Танцы; Активность` ❌ (точка с запятой и заглавные не распарсятся)

## Что проверяет валидатор

### ❌ Ошибки (блокируют сборку)

Если найдена хотя бы одна ошибка — БД **не пересобирается**, старая версия сохраняется.

| Проверка | Пример ошибки |
|----------|---------------|
| Отсутствует обязательная колонка | Удалили или переименовали «Направление» |
| Пустое Направление | Строка 5: ячейка пуста |
| Пустое Название коллектива | Строка 12: ячейка пуста |
| Пустой Возраст | Строка 8: ячейка пуста |
| Пустая Площадка | Строка 3: ячейка пуста |
| Возраст «наоборот» | `12-7 лет` — минимум больше максимума |

### ⚠️ Предупреждения (не блокируют, но влияют на качество)

Сборка продолжится, но бот может работать хуже.

| Проверка | Чем грозит |
|----------|------------|
| Лишние пробелы в Направлении | `Шахматы ` и `Шахматы` — два разных направления в админке |
| Нестандартное значение Платное/Бюджет | Бот не определит стоимость программы |
| Неизвестная площадка | Бот не отфильтрует по адресу |
| Нестандартный формат возраста | Бот не отфильтрует по возрасту ребёнка |
| Ссылка не похожа на URL | Родитель не сможет перейти по ссылке |
| Пустое Расписание | Бот не расскажет про дни занятий |
| Пустое Платное/Бюджет | Бот не определит стоимость |
| Дубликаты программ | Одна и та же программа в выдаче дважды |
| Лишние столбцы | Не используются ботом, просто предупреждение |
| Пустые строки | Мусорные строки в конце файла |
| Возраст > 18 лет | Возможная опечатка (это детский центр) |

### ℹ️ Рекомендации (не влияют на работу)

| Проверка | Что улучшится если исправить |
|----------|------------------------------|
| Не указан педагог | Бот не сможет рассказать про педагога |
| Пустые теги | Поиск по ключевым словам будет менее точным |
| Нестандартный порядок колонок | Удобство ручного редактирования |

## Как работает сборка БД

### Этап 1: Валидация

`build_db.py` автоматически вызывает `validate_programs.py`. При ошибках — остановка.

### Этап 2: Загрузка программ

Каждая строка из `programs.xlsx` превращается в запись таблицы `programs`:
- Парсится возраст (`7-12 лет` → `age_min=7`, `age_max=12`)
- Нормализуется площадка (`пр. Раевского 5/2` → `Раевского`)
- Определяется бесплатность (`Бюджет` → `is_free=1`)
- Формируется текст для поиска (все поля склеиваются)
- Формируется текст-чанк для LLM (человекочитаемый формат)

### Этап 3: Генерация тегов

Для каждой программы создаются записи в `program_tags` из трёх источников:

1. **Автоматически из `synonyms.json`** — по совпадению направления/названия с `tag_synonyms`.
   Например, «Хореографический ансамбль Забава» → тег `хореография`.

2. **Из колонки «теги» в Excel** — напрямую через split по запятой.
   Например, `танцы, активность, осанка` → три тега.

3. **Тег стоимости** — `бюджет` или `платно` добавляется автоматически.

### Этап 4: Загрузка FAQ

Из `FAQ.docx` извлекаются пары «вопрос — ответ». Вопросы определяются по наличию `?` в строке.

### Этап 5: Полнотекстовые индексы

Создаются FTS5-индексы для быстрого поиска по тексту программ и FAQ.

### Этап 6: Векторные эмбеддинги (отдельный шаг)

`build_vectors.py` (запускается отдельно после `build_db.py`) генерирует
векторные представления программ и FAQ через модель `intfloat/multilingual-e5-base`
и сохраняет их в `knowledge.db` через расширение `sqlite-vec`.

## Типичные сценарии

### Клиент прислал обновлённый файл программ

```bash
# 1. Положите файл в data/
cp /path/to/новый_programs.xlsx data/programs.xlsx

# 2. Запустите сборку (валидация автоматически)
python services/db/build_db.py

# 3. Если ошибки — исправьте файл и повторите шаг 2

# 4. Пересоберите эмбеддинги
python services/db/build_vectors.py

# 5. Перезапустите бота
sudo systemctl restart ddt-bot
```

### Клиент добавил новую программу

Он добавляет строку в конец Excel. Обязательно заполнить:
Направление, Название коллектива, Возраст, Платное/Бюджет, Площадка.

Остальные поля рекомендуется заполнить для лучшего качества ответов,
но их отсутствие не заблокирует сборку.

### Клиент удалил программу

Удаляет строку из Excel. Пересборка БД автоматически уберёт её из поиска.

### Клиент случайно сломал файл

Валидатор покажет что именно не так:

```
🛑 Найдено 2 ошибок:
   ❌ Строка 15: пустое Направление.
   ❌ Отсутствуют обязательные колонки: ['теги']

🛑 Сборка БД ОТМЕНЕНА. Исправьте ошибки и запустите снова.
   (БД не была изменена)
```

Бот продолжает работать на предыдущей версии БД.

## Частые ошибки клиента и как их избежать

| Что делает клиент | Что происходит | Как избежать |
|-------------------|----------------|--------------|
| Переименовал колонку | ❌ Сборка отменена | Названия колонок менять нельзя |
| Добавил лишний столбец | ⚠️ Предупреждение, сборка идёт | Лишние столбцы не мешают |
| Оставил пробел в конце «Шахматы » | ⚠️ Дубли в админке | Убирать пробелы в ключевых полях |
| Написал возраст «от 7» вместо «7 лет» | ⚠️ Бот не фильтрует по возрасту | Формат: `N-M лет` или `N лет` |
| Удалил все строки | ❌ Файл пуст | Не удалять все данные |
| Сохранил как .csv вместо .xlsx | ❌ Не удаётся прочитать файл | Только формат .xlsx |
| Вставил строку с формулами | Зависит от формулы | Только значения, не формулы |
